Project Highlight: Freelance Business Companion

I created an app from the ground up to handle most finance-related tasks of a freelance business owner. Users can manage income, expenses, visualize data, manage tasks, and see an AI-generated summary that provides relevant actionable information based on users’ individual data. 

Tech stack: React 18, React Router, Vite, Tailwind CSS, Recharts, Supabase, Ollama, JavaScript

What I would do differently: I realized from exploring classmates’ sites that I could have reduced friction further by combining my income and expense interfaces into one. The other thing I would have done differently if I had more time would be to flush out the charts feature to allow for users to create custom charts in order to improve usefulness.

Link: https://dmlbizcompanion.netlify.app/ (Ollama only running locally)
Github: https://github.com/dleggett300/claude-midterm
